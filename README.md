# CECYTED Inventory Móvil 📱

Aplicación móvil de gestión y control de inventarios desarrollada para el **Colegio de Estudios Científicos y Tecnológicos del Estado de Durango (CECYTED)**. Este proyecto soluciona los problemas de control, ineficiencia y falta de seguimiento sobre el estado y asignación de activos tecnológicos e institucionales en el estado.

---

## Mi Impacto en el Proyecto (Frontend & Core Logic)
En este proyecto desempeñé un rol crítico en el desarrollo de la aplicación móvil y la lógica central del sistema bajo la metodología ágil KANBAN, encargándome de:
* **Desarrollo Frontend Multiplataforma:** Programación de toda la interfaz móvil de la aplicación utilizando **React Native** y **JavaScript**, garantizando una experiencia nativa fluida y limpia para el personal institucional.
* **Módulo de Autenticación Seguro:** Diseño e implementación de la lógica de inicio de sesión (**Log-in**), gestión de estados de sesión de usuario y rutas protegidas en la aplicación.
* **Lógica de Control de Equipos e Inventario:** Arquitectura y desarrollo del flujo completo para el registro de activos, asignación directa de equipos a empleados y visualización del stock.
* **Bitácora Digital de Mantenimiento:** Implementación de la sección para el reporte de incidencias, historial de estado físico y control de mantenimiento de cada equipo tecnológico.

---

## Stack Tecnológico

* **Frontend:** React Native, React, JavaScript (ES6+)
* **Backend & API:** Node.js / Arquitectura de servicios
* **Base de Datos:** MySQL (Bases de datos relacionales)
* **Gestión de Proyecto:** Metodología Ágil (KANBAN)

---

## Características Clave

* **Diseño Intuitivo:** Interfaz enfocada en la facilidad de uso para personal administrativo y operativo en campo.
* **Persistencia y Sincronización:** Consumo eficiente de servicios para mantener actualizadas las bitácoras digitales con la base de datos relacional MySQL de la institución.
* **Control de Roles:** Flujos de trabajo diferenciados según el tipo de empleado autenticado en el sistema.
